# AniTube TV

Простий клієнт [anitube.in.ua](https://anitube.in.ua) для Android TV / проєкторів, яким зручно керувати пультом.

## Керування в плеєрі

| Кнопка | Дія |
|---|---|
| ← / → | перемотка на 10 с (утримуй — швидше) |
| ↑ | пропустити опенінг (+85 с) |
| OK | пауза / продовжити |
| ↓ | показати / сховати панель |
| ☰ або довге OK | меню: наступна/попередня серія, список серій, налаштування |
| ⏭ / ⏮, CH+ / CH− | наступна / попередня серія |

Крок перемотки, довжину пропуску, максимальну якість і автоперехід на наступну серію можна змінити в налаштуваннях.
Застосунок запам'ятовує, де ти зупинився в кожній серії, і показує переглянуті серії зеленим.

## Збірка

APK збирається автоматично через GitHub Actions і викладається в Releases як `anitube-tv.apk`.
